# 📚 library-management-system
A complete Library Management System built using SQL Server.

## 🔨 Tools Used 
- SQL Server Management Studio (SSMS)

## 📋 Tables
1. ''books'' : stores all library books
2. ''members'' : stores library members
3. ''loans'' : tracks book borrowing
4. ''fines'' : tracks late return penalties
5. ''recommendations'' : member book reviews and ratings

## ⚡Features
- Track book availability
- Manage member records
- Monitor overdue books
- Calculate fines for late returns
- Book recommendation and rating system

## In this project the Queries Included
- View all borrowed books with member names
- Find overdue books
- Find members with unpaid fines
- Find highest rated books
